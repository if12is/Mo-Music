## ما هو مو ميوزك؟

**مو ميوزك** مشغّل موسيقى حديث يعمل أولًا بدون إنترنت، مع هوية بصرية جديدة ولغة عربية افتراضية واتجاه RTL.

Mo Music is a modern offline-first Flutter music player. Arabic is the default language, Cairo is the bilingual UI font, and in-app updates come from **this repository** (`if12is/Mo-Music`), not from the original upstream project.

### ملاحظات التثبيت

- **Android**: استخدم `MoMusic-android-universal.apk` أو `app-release.apk` لأي جهاز. ملفات `app-arm64-v8a-release.apk` / `app-armeabi-v7a-release.apk` / `app-x86_64-release.apk` أخف حسب المعالج.
- **Windows**: ثبّت `MoMusic-windows-installer.exe` أو فك `MoMusic_Portable.zip`.
- **Linux**: يحتاج `libmpv` و `libgtk-3`.
- **macOS**: فك الضغط ثم اسحب التطبيق إلى Applications. إذا منع Gatekeeper التطبيق: **زر أيمن → فتح**.
- **iOS**: ثبّت `MoMusic-ios-unsigned.ipa` عبر [SideStore](https://sidestore.io).

## التحديثات والإصدارات

التطبيق يتحقق من الإصدارات عبر `if12is/Mo-Music` فقط:

1. `UPDATE_CHECK_URL` إن وُجد في `.env`
2. `distribution/update-check.json` على فرع `master`
3. GitHub Releases/Tags: [if12is/Mo-Music/releases](https://github.com/if12is/Mo-Music/releases)

Android داخل التطبيق يحمّل `MoMusic-android-universal.apk` من أحدث إصدار.

لنشر إصدار جديد:

```bash
# 1) ارفع رقم الإصدار في pubspec.yaml مثل 2.5.0+74
# 2) ادفع التغييرات إلى master
# 3) أنشئ tag وأصدر Release في GitHub
git tag v2.5.0
git push origin v2.5.0
```

GitHub Actions يبني كل المنصات ويرفع كل أسماء الملفات أعلاه إلى نفس الـ Release.

## البناء من المصدر

```bash
git clone https://github.com/if12is/Mo-Music.git
cd Mo-Music
cp .env.example .env
flutter pub get
flutter run
```
